
# Student Management CRUD Application
---

## 🚀 Project Overview

This is a **Simple Student Management CRUD Application** built with modern web technologies and Oracle database. It allows you to **create, read, update, and delete students** efficiently.  

**Technologies Used:**

- **Frontend:** HTML, CSS, TailwindCSS, JavaScript, jQuery, AJAX  
- **Backend:** Python (Flask, Flask-CORS ), 
- **Database:** Oracle 11g / 19c
