## 🚀 Project Overview

This is a **full-stack Student Management CRUD Application** built with modern web technologies and Oracle database. It allows you to **create, read, update, and delete students** efficiently.  

**Technologies Used:**

- **Frontend:** HTML, CSS, TailwindCSS, JavaScript, jQuery, AJAX  
- **Backend:** Python (Flask)  
- **Database:** Oracle 11g / 19c  
- **Other:** Flask-CORS for cross-origin requests
